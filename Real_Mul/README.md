# real_mul — умножитель чисел с плавающей точкой

- `real_mul.v` — верхнеуровневый модуль умножителя
- `Op_Analyzer.v`, `Pre_res.v`, `rounding_module.v`, `Exp_corr.v` — внутренние модули

- `tb_real_mul.v` — самопроверяющийся testbench
